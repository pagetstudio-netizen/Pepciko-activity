Use the supplied Mixx TG mark for T-Money/Mixx, Moov Africa for Moov, the cropped MTN Mobile Money mark for MTN, and the supplied Orange and Wave marks for those operators. When a manual payment number has an Admin-configured logo, show that logo instead of the shared fallback.

**Why:** On 2026-11-19, the user supplied logos for the payment operators and confirmed that the MTN logo should be cropped from the three-logo image and integrated.

**How to apply:** Keep operator-name matching consistent in every payment selection flow, use the supplied marks when the provider has no manual override, and do not replace an explicit Admin logo.
